Tú editas canales localmente → Publicar en GitHub → GitHub Actions genera las listas automáticamente → el Worker sirve siempre la versión más reciente. Sin servidores, sin costes.

1️⃣ GitHub — subir canales
Configura GitHub en Ajustes primero (usuario, repo y token).

Sube raul_channels.json y config.json a tu repo de GitHub. Esto activa automáticamente GitHub Actions, que generará las listas M3U y las publicará en GitHub Pages.

2️⃣ Cloudflare Worker — URL permanente

El Worker sirve las listas en tiempo real (descarga fuentes IPFS al momento + lee tus canales RAUL desde GitHub). Una vez desplegado, nunca más hay que tocarlo — se actualiza solo cuando haces push a GitHub.

Configura Cloudflare en Ajustes para desplegar automáticamente. O copia el script manualmente.
Tu URL permanente:
Instrucciones manuales (si no quieres usar la API)
  1. Ve a cloudflare.com → Workers & Pages → Create → Worker
  2. Nombre: m3u-manager → Deploy → Edit code
  3. Pega el script copiado con el botón de arriba → Save & Deploy
  4. Tu URL: https://m3u-manager.TU_USUARIO.workers.dev/m3u?format=acestream
🚀 Primera vez — Configuración inicial GitHub
  1. Crea un repo en github.com (puede ser privado). Nombre: m3u-manager
  2. Ve a Settings → Pages → Source: Deploy from a branch → branch: gh-pages
  3. Crea un Personal Access Token: Settings → Developer settings → Fine-grained tokens
    Permisos: Contents: Read and Write, Actions: Read
  4. Pon el token en Ajustes de esta app
  5. Haz el primer push desde aquí → Actions se activa automáticamente
